# Introduction

Nodal AI is a modular, secure Stellar Agent Kit with PayFi / x402 support. It bridges the gap between AI reasoning and Stellar's high-speed, low-cost network.

## What is Nodal AI?

Nodal AI provides:
- **Autonomous PayFi**: Built-in support for the x402 payment standard
- **Modular Architecture**: Easy tool swapping and workflow orchestration
- **Safety-First Design**: Transaction simulation and externalized secrets

## Key Features

- [x] Secure Stellar transaction handling
- [x] x402 payment protocol support
- [x] MCP (Model Context Protocol) integration
- [x] Extensible tools system
- [x] Comprehensive API documentation
