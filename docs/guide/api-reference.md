# API Reference

The API reference is generated from the TypeScript source code using TypeDoc.

## Viewing the API

The full API documentation is generated by TypeDoc and can be accessed via the generated HTML output.

## Modules

### Core Modules

- `backend/index.ts` - Main entry point
- `backend/agent.ts` - Agent implementation
- `backend/tools/*.ts` - Tool implementations
- `backend/errors.ts` - Error definitions
- `backend/nonce_store.ts` - Nonce management
- `backend/spending_tracker.ts` - Spending tracking

## Tool Schemas

Machine-readable tool schemas are available at:

- [tools.schema.json](/tools.schema.json) - JSON Schema for all tools

Generate tool schemas with:

```bash
npm run tools:schema
```

## Generating Documentation

To regenerate the API documentation:

```bash
npm run docs:generate
```

This runs TypeDoc and outputs to `docs/api/`.

## Accessing Generated Docs

After running `npm run docs:generate`, the API documentation will be available in the `docs/api/` directory as static HTML files.
